# FrontFind
<h3><a href="https://front-find.onrender.com/">[Live app here]</a></h3>

FrontFind is a web application that recommends the best frontend framework for your project based on your preferences.

<img src="https://github.com/leo-garcianie/front-find/blob/main/screenshots/front-find-img1.png?raw=true" width="700px" height="auto"/>

## Key features:
- Framework Recommendation: Intelligent algorithm that analyzes project requirements and suggests optimal frontend frameworks
- Interactive Questionnaire: User-friendly form to capture project preferences and technical requirements
- Responsive Design: Fully responsive interface optimized for all devices

## Technologies

## Frontend (React)
- React – User interface
- Tailwind CSS – Styling
- Axios – HTTP requests to backend
- React Router – routing/navigation
- Recharts – Framework comparison charts
- Swiper – carousel/slider

### Backend (Python + Flask)
- Flask – lightweight web framework
- flask-cors – enables frontend–backend communication
- python-dotenv – load environment variables
